# 秦晖 · 认知档案

> 假如还没有 1，那么谈论 2 与 10 的中位数有什么意义？

一个可以直接装进 AI 的**思维档案**——用秦晖的方式分析问题。

这不是提示词模板，也不是让模型学他的口吻说话。它注入的是他的**认知上下文**：他的信念从哪来、在哪些具体场景下做过什么决策、他承认自己错在哪、他明确说不知道什么。

区别在于：模仿语气得到的是一段像他说话的文本；植入认知上下文得到的是**他遇到新问题时那套拆解方式**。

## 怎么用

**方式一：作为 Skill 安装**

放进你所用工具的 skills 目录即可被自动识别：

```bash
# WorkBuddy
git clone <本仓库地址> ~/.workbuddy/skills/qin-hui-perspective

# Claude Code
git clone <本仓库地址> ~/.claude/skills/qin-hui-perspective
```

之后直接对话：

```
> 用秦晖的方式帮我分析这个问题：……
```

**方式二：手动注入**

把 `SKILL.md` 全文作为系统提示的一部分交给任意模型。文件是自包含的，不依赖其他文件即可工作——`references/` 只是提取证据，供人查阅。

## 文件结构

```
SKILL.md                          档案本体（自包含，直接可用）
references/

    02-extraction-notes.md        提取记录，逐条标注出处行号与优先级
    03-key-quotes.md              关键原文引用
```

## 档案构成

| 部件 | 条数 | 质量约束 |
|------|------|----------|
| 信念及其来源 | 10 | 每条都带"形成故事"——谁让他想明白的、从哪份材料里读出来的 |
| 真实决策复盘 | 6 | 每个都带事后反思，不粉饰 |
| 栽过的跟头 | 4 | 全部为本人公开承认 |
| 内在矛盾 | 4 | 保留张力，不替他自圆其说 |
| 明确不懂的 | 8 | 划定认知边界 |
| 思维习惯 | 10 | 可操作的判断动作 |
| 红线 | 6 | 他绝不会做的事 |

几条最能体现其方法特征的思维习惯：

- **听到笼统对象先要求拆开**——"传统"里有儒、法、道，"启蒙"里有反秦和反儒，简单肯定或否定都不成立
- **先问这是对谁说的**——同一个"无为"，对皇上讲和对百姓讲，意思正好相反
- **把对手的前提推到他自己坐不住的地方**——从"拔一毛"一路推到"砍脑袋"
- **用一只白渡鸦否证全称命题**
- **把名词之争还原成事实之争**

## 蒸馏方法

采用「仓颉 · 认知植入术」的四条铁律：

1. 没形成故事的信念不进
2. 没反思的决策不进
3. 不写 Step 1 / 2 / 3 这类推理步骤
4. 全部第一人称

第 3 条是关键。写推理步骤等于把模型本来就会的东西重新教一遍，占位置还没用。真正有价值的是那些**模型不可能从通用训练数据里知道的东西**——具体的人、具体的事、具体的失败。

## 素材来源

五份一手素材，分两类，互补性很强：

- **讲座逐字实录**（《中国思想史》39 集、《新文化运动百年祭》两篇）——分析框架与史料处置方式暴露得最完整，是提取"怎么想"的最佳材料；弱项是几乎不含个人经历。
- **著作序言**（《共同的底线》《田园诗与狂想曲》）——含生平自述、研究方法的发生过程、对批评者的逐条回应。这是"信念形成故事"与"失败与自我修正"两栏的唯一来源。

**被排除的素材**（详见 `01-sources.md`）：

- 秦晖评述塔利班系列文章——2021 年后的即时国际时评。时评不构成稳定的分析方法，固化进档案会把分析工具变成立场输出器。
- 《隋唐制度渊源略论稿》——陈寅恪著作，非秦晖。纳入会把两个人的思维混在一起。

**关于原始文本**：`references/source-text/` 下的 epub 解包全文受版权限制，未随仓库分发。档案中的行号引用以该解包文本为准，如需核对请自行获取书目并按同法解包，行号可能因版本而异。

## 已知局限

- 素材以 2016 年讲座与 1990—2013 年著作为主，**不覆盖他近年的表述变化**。
- 讲座实录的口语特征与书面文章有差异，`SKILL.md` 的表达偏好一节以讲座为准。
- 档案刻画的是方法而非立场。它应该能帮你分析任何问题，包括那些秦晖本人没谈过的问题——如果它开始复述他的结论而不是用他的方法，那就是失效了。
